No operating system. The same programs.

Prismio against C (clang -O3) and Rust (no_std, opt-level 3) on bare-metal AArch64: no C library, no allocator, no startup files. One shared boot harness links into all three, so the only code that differs is the benchmarks. Each image runs under QEMU and every workload is counted in guest instructions, which is exact and repeatable, with identical checksums across all three languages.
